# 交接单 · 《任务名》

> **用途**：把一个窗口（评审/规划）的结论交接给另一个全新窗口去落地实现，避免把巨型上下文原样带过去。评审窗口把本文件填满，新窗口只读这一份即可开工。
>
> **用法**：把本文件从 `docs/plans/HANDOFF_TEMPLATE.md` 复制到 `docs/plans/<任务名>/HANDOFF.md` 再填。填写时只写文件、不改代码。字段结构对齐全局 CLAUDE.md「压缩必须保留的 6 项」。
>
> **状态**：⬜ 起草中 / ✅ 可交接　｜　评审窗口填完把状态改成「✅ 可交接」，新窗口才开始。

---

## 六、关键约束与用户纠正 *(compact 第 4、6 项：设计决策 + 用户明确指令)*

## 七、验证方式 *(compact 第 5 项)*

> 新窗口落地后如何自证做对了。命令 + 判读标准。

```bash
./mvnw clean compile          # 只编译，不校验 DRL
./mvnw test                   # 跑测试
# 启动冒烟（DRL 改动必须，才会触发 lazy compile）：
DB_HOST=localhost DB_PORT=3306 DB_NAME=drools_demo DB_USERNAME=root DB_PASSWORD=**** \
  ./mvnw spring-boot:run
# 或无 MySQL：./mvnw spring-boot:run -Dspring-boot.run.profiles=h2
# 冒烟请求：
# curl -X POST localhost:8081/<接口> -H 'Content-Type: application/json' -d '{...}'  → 期望 {...}
```

- **判读标准**：《编译过 / N 个测试全绿 / 冒烟接口返回 X》
